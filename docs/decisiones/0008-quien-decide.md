# 0008 — Decide el responsable técnico

- **Estado:** aceptada
- **Fecha:** 2026-10
- **Decide:** responsable técnico

## Contexto

Hoy desarrolla una sola persona, hasta nuevo aviso. La jefatura de desarrollo está vacante.

## Decisión

Las decisiones técnicas las toma el responsable técnico (el desarrollador). Las de negocio, Gerencia o el área dueña del proceso. Los agentes no deciden nada abierto: preguntan.

## Consecuencias

- Toda decisión que afecte más que la tarea actual se escribe en un ADR o en `pendientes.md` antes de seguir. Lo que solo está en un chat no existe.
- Si se suma otra persona, se revisa este ADR (consenso, y mayoría si hay tres).
